# Plan: Software Bill of Materials (P4.2)

Rolle: Umsetzungsplan (Detaildokument, Skelett)
Grundlage: `../CRA_Compliance_Checklist.md`
Maßnahme: P4.2
CRA-Bezug: Annex I, Teil II, Nr. 1 (Pflicht-Nr. 11) und Art. 13(5) (Pflicht-Nr. 22)
Datum: 2026-09-28
Hinweis: Skelett. Abschnitt 2 ist verifiziert, die Abschnitte 3 bis 6 sind zu füllen.

## 1. Objective

Maintain a machine readable SBOM for the shipped firmware and web assets, and use it as the basis
for vulnerability handling (P4.5).

## 2. Current State (verified 2026-09-28)

Direct dependencies as declared in `platformio.ini`:

| Komponente | Version / Quelle |
|---|---|
| Framework Arduinofor ESP32 (arduino-esp32 core, ESP-IDF) | Platform `espressif32`, board `arduino_nano_esp32` |
| bblanchon/ArduinoJson | 7.4.1 |
| adafruit/Adafruit ADS1X15 | 2.5.0 |
| imax9000/Arduino-PID-Library | Git dependency, no version pin |
| littlefs | Bundled with the core (`board_build.filesystem = littlefs`) |
| chart.js | Shipped as `data/chart.min.js`, version to be determined |

No SBOM exists. Transitive dependencies of the core (ESP-IDF components, mbedTLS, FreeRTOS) are not
listed anywhere. The PID library is not pinned to a commit or tag, which makes builds non reproducible.
