## 1. Objective

Fix the support period, publish the end date and define what support covers, including how security
updates are delivered during that period.

## 2. Current State (verified 2026-09-28)

- No support period is defined and no end date appears anywhere: not in the user manual
  (`LaTeX/manual/VentCon_User_Manual.tex`), not in the web interface, not in the product data.
- Firmware version in the working tree: 2.7.4 (`VERSION`, generated by `inject_version.py` at build
  time, mirrored as `VENTCON_VERSION` in the web UI).
- Update delivery is currently local only, see P4.3.
